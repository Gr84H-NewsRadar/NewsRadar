# NewsRadar

[![CI/CD Pipeline](https://github.com/Gr84H-NewsRadar/NewsRadar/actions/workflows/ci.yml/badge.svg)](https://github.com/Gr84H-NewsRadar/NewsRadar/actions/workflows/ci.yml)

Sistema de monitorización de noticias en medios de comunicación y fuentes oficiales.

## Descripción
NEWSRADAR permite monitorizar canales RSS, crear alertas por palabras clave,
clasificar noticias según categorías IPTC y recibir notificaciones.

## Estructura del proyecto
- `docs/` — Documentación técnica y ADRs
- `newsradar_api/` — Backend API REST (FastAPI + PostgreSQL)

## Tecnologías
- Python 3.11, FastAPI
- PostgreSQL
- Docker y Docker Compose
